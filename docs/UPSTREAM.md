# Upstream reference

Spoken Page Enhanced is based on the open-source Spoken Page project by JCDeSantis.

Original repository:

https://github.com/JCDeSantis/spoken-page

At the time this documentation was prepared, the upstream repository describes Spoken Page v1.3 as a responsive subtitle-first Audiobookshelf companion with complete-library search, listening status/Want to listen, remembered views, series improvements, progress-save feedback, account-synced pinned books, native Audiobookshelf playback sessions, multi-track progress sync, chapter/timeline navigation, playback speed and subtitle timing, sleep timer, focused/separate player views, keyboard/media-session controls, SRT/VTT discovery, local subtitle upload, subtitle-focused reading, and account-synced preferences.

The upstream repository is MIT licensed. Keep its license and attribution notices with the original portions of the code.
