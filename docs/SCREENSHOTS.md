# Screenshots

Put public screenshots in `docs/images/`.

Recommended naming:

```text
01-library.png
02-book-details.png
03-fullscreen-readalong.png
04-appearance.png
05-personal-lists.png
06-bookmarks.png
07-visualizer.png
```

Avoid screenshots containing:

- real usernames
- local drive letters
- personal folder paths
- private Audiobookshelf server URLs/IPs
- private book/library metadata
- authentication/session information

## README embedding

```md
![Library](docs/images/01-library.png)
![Fullscreen read-along](docs/images/03-fullscreen-readalong.png)
```
