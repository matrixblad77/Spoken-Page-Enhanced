# AI-Assisted Development Notice

Spoken Page Enhanced was developed with substantial AI assistance for:

- code generation
- debugging
- refactoring
- TypeScript error diagnosis
- UI design iteration
- documentation
- test/checklist creation

The human maintainer remains responsible for deciding which changes are accepted, testing the application, and publishing releases.

AI assistance should not be treated as a guarantee of correctness or security. Users should review release notes, keep backups, and test new releases in their own environment before relying on them.
