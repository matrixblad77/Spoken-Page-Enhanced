# Security Policy

## Supported versions

Security fixes should target the newest Enhanced release.

## Reporting a security issue

Please do not publish credentials, tokens, private URLs, or sensitive logs in a public GitHub issue.

Use GitHub's private security reporting tools when available, or contact the maintainer privately.

## Deployment reminders

- Keep `.env` files private.
- Use a stable high-entropy application secret.
- Avoid exposing an unauthenticated installation directly to the public internet.
- Use HTTPS for public deployments.
- Do not publish Audiobookshelf access tokens.
