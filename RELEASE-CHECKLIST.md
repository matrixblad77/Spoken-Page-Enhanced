# Release checklist

## Code

- [ ] Docker build succeeds.
- [ ] TypeScript/typecheck succeeds.
- [ ] Tests succeed.
- [ ] No unresolved missing-file imports.
- [ ] No temporary verification scripts are required by users.
- [ ] All Enhanced-only source files needed by imports are included.

## Branding

- [ ] Main title says Spoken Page Enhanced.
- [ ] Enhanced version is current.
- [ ] Upstream version is clearly identified as the base.
- [ ] Original project link is present.

## Privacy

- [ ] No `.env` file.
- [ ] No secrets/tokens/cookies.
- [ ] No private library paths.
- [ ] No personal screenshots.
- [ ] No private logs.

## Documentation

- [ ] README updated.
- [ ] INSTALL updated.
- [ ] CHANGELOG updated.
- [ ] AI-assisted development notice present.
- [ ] Upstream credit present.
- [ ] Screenshots updated.

## Release

- [ ] Git tag matches the Enhanced version.
- [ ] Tested ZIP attached to Release.
- [ ] Release notes explain major changes.
